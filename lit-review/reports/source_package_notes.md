# Pose Embedding and Contextual Metric Learning Literature Review - Source Package Notes

This archive was prepared from the literature review on robust contextual metric learning for pose-based human motion retrieval.

Core source buckets:

1. Brian Kulis / contextual metric learning
2. Deep metric learning, ranking losses, and contextual similarity
3. Pose embedding and view-invariant pose retrieval
4. Skeleton-based action recognition architectures
5. Motion representation learning and text-motion retrieval
6. Pose-estimation robustness and incomplete skeleton methods
7. Public datasets: NTU RGB+D 120, AMASS, SportsPose, Human3.6M/H3WB, FineGym, UCF101, KIT Motion-Language, BABEL
8. Public repositories suitable as baselines: MotionBERT, MMAction2/PoseC3D, ST-GCN, POEM/Pr-VIPE, contextual metric learning repo, MotionCLIP, text-to-motion-retrieval

The archive intentionally separates paper links from code repositories because codebases should usually be cloned from upstream to preserve license files and current commit history.
