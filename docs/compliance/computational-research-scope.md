## Scope of the work

This project is a computational machine-learning study. It trains and evaluates
models using an existing, licensed set of HRNet-derived pose annotations from
NTU RGB+D 120 and a pretrained MotionBERT checkpoint. The project does not:

- recruit participants;
- interact or intervene with participants;
- collect new participant data;
- use direct identifiers or attempt re-identification; or
- involve animals or animal-derived specimens.

All project activity is performed on computers. The source pose annotations
were nevertheless derived from recordings of people, so this project should
not be described as containing no human-derived data. Dataset access,
processing, storage, and reporting remain subject to the applicable license and
Boston University requirements.
